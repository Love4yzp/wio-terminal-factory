# Wio Terminal 整机功能测试与检修项目 (wio-terminal-factory)

本项目用于对 **Seeed Studio Wio Terminal** 进行整机硬件功能检验，主要服务于 **用户使用后退回/返修设备的故障定位与检修筛查（RMA Triage）**，同时支持整机功能验收。

测试固件烧录至设备后，将对关键硬件模块进行逐项检测，并最终在 Wio Terminal 屏幕上直接给出 **「通过 (PASS)」** 或 **「需检修 (REPAIR)」** 的结论，同时列明各分项的通过/失败状态与具体原因；同时通过 USB 串口输出结构化日志（用于屏幕损坏无法显示时的兜底排查）。用户收货后可直接刷写自己的固件覆盖本测试程序。

---

## 快速使用

* **测试工位（无需 pio）**：`python3 tools/auto_flash.py`。插上设备后，脚本会自动识别设备、比对版本、按需烧录 `dist/` 中的预编译固件，并把串口结果显示在终端、存到 `logs/`。
* **开发者编译（需要 PlatformIO）**：`pio run`（会同步更新 `dist/`）。详见 [开发说明](docs/development.md)。
